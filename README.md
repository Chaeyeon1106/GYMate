# GYMate 🏋️

헬스장을 같이 다니는 친구들끼리 방문 시간을 공유하고, 운동/식단 기록을 남기는 앱입니다.
빌드 도구 없이 순수 HTML/CSS/JS + Firebase로 만들어졌습니다.

## 주요 기능
- 캘린더에 내가 갈 시간을 등록하면 그룹 친구들이 실시간으로 확인 (언제든 수정 가능)
- 운동 인증사진 업로드 (삭제하지 않는 한 영구 보관)
- 운동 시간(분)/장소/메모 기록
- 식단 사진 + 식사 종류(아침/점심/저녁/간식) 기록
- 기록마다 "그룹에 공개" / "나만 보기" 선택 가능
- 운동 목표 문구 저장

## 1. Firebase 프로젝트 설정

1. [Firebase 콘솔](https://console.firebase.google.com/)에서 새 프로젝트를 만듭니다.
2. 왼쪽 메뉴에서 아래 3가지를 켭니다.
   - **Authentication** → 시작하기 → 로그인 방법에서 **이메일/비밀번호** 사용 설정
   - **Firestore Database** → 데이터베이스 만들기 (테스트 모드가 아니라 아래 규칙을 적용할 예정이니 위치만 정하고 생성)
   - **Storage** → 시작하기 (기본 설정으로 생성)
3. 프로젝트 설정(⚙️) → **내 앱** → 웹 앱 추가(</> 아이콘) → 앱 등록
4. 발급된 `firebaseConfig` 값을 복사해서, 이 프로젝트의 `firebase-config.js` 파일 안의 값들을 교체합니다.

## 2. 보안 규칙 적용

Firebase 콘솔에서:
- **Firestore Database → 규칙** 탭에 이 프로젝트의 `firestore.rules` 내용을 붙여넣고 게시
- **Storage → 규칙** 탭에 이 프로젝트의 `storage.rules` 내용을 붙여넣고 게시

(Firebase CLI가 설치되어 있다면 `firebase deploy --only firestore:rules,storage:rules` 로도 배포할 수 있습니다.)

## 3. 로컬에서 실행하기

Firebase Auth는 `file://`로 직접 열면 정상 동작하지 않습니다. 아래처럼 간단한 로컬 서버로 열어주세요.

```bash
npx serve .
```

또는 VS Code의 Live Server 확장을 사용해도 됩니다. 이후 안내된 주소(예: `http://localhost:3000`)로 접속하세요.

## 4. 사용 흐름

1. 회원가입 (닉네임/이메일/비밀번호)
2. 그룹 만들기 (그룹 이름 입력 → 6자리 초대코드 자동 생성) 또는 초대코드로 참여
3. 마이 탭에서 초대코드를 복사해 친구에게 공유 → 친구는 "코드로 참여"로 같은 그룹에 합류
4. 캘린더 탭에서 날짜를 눌러 방문 시간 등록/수정, 운동 기록·식단 탭에서 사진과 기록 추가


## 규칙 (MVP 범위)
- 그룹당 일정은 "본인 것만" 등록/수정할 수 있음 (친구 일정을 대신 수정하는 기능은 없음).
- 운동/식단 기록도 작성자 본인만 수정·삭제할 수 있음
- 사진은 Storage에 영구 저장되며, 앱에서 별도 삭제 기능은 제공하지 않음
- Storage 사진은 로그인한 사용자라면 URL을 알 때 접근 가능한 구조(다운로드 URL 자체가 추측하기 어려운 토큰을 포함)
- "그룹에 공개"로 설정한 운동/식단 기록은 (Firestore list 쿼리 규칙의 한계로) 정확한 경로를 안다면 이론상 다른 그룹의 로그인한 사용자도 읽을 수 있는 구조. 초대코드로만 가입하는 폐쇄형 앱이라 실질 위험은 낮지만, "나만 보기"로 설정한 기록은 항상 작성자 본인만 읽을 수 있도록 강하게 보호.
